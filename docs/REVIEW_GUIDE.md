# 扩展审核指南

审核目标是控制官方市场准入和发现明显风险，不是对第三方代码作形式化安全证明。

## 必查项目

1. 确认源码仓库公开、Publisher 账号映射正确、许可证获得 OSI 认可
2. 确认标签指向版本清单记录的提交，比较上一个市场版本至当前标签的完整差异
3. 检查网络目标、凭据处理、文件访问、子进程、设备和浏览器数据使用
4. 检查声明权限是否覆盖实际行为，新增权限是否有清晰理由
5. 检查构建说明、依赖锁文件和 Release 产物来源
6. 运行 CI，确认 `.ppx`、主镜像字节、SHA-256 与 registry 生成结果一致

可以使用静态分析器、杀毒引擎或 AI 辅助定位风险，但最终合并由维护者明确决定
